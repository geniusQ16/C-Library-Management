\# C 语言图书管理系统



一个基于 C 语言实现的图书管理系统，主要用于练习结构体、文件操作、函数设计和基础数据管理。



\## 项目简介



本项目通过控制台菜单实现图书信息管理，使用文件保存图书数据，支持程序关闭后再次运行时读取已有记录。



\## 主要功能



\- \*\*图书录入：\*\* 添加图书编号、书名、作者、出版社等信息。

\- \*\*图书查询：\*\* 支持按图书编号、书名等条件查询。

\- \*\*图书修改：\*\* 修改已有图书的信息。

\- \*\*图书删除：\*\* 根据指定条件查找并删除图书记录。

\- \*\*文件存储：\*\* 将图书信息保存至本地数据文件。

\- \*\*菜单交互：\*\* 通过控制台菜单选择不同操作。



\## 技术栈



\- 编程语言：C

\- 编译工具：GCC

\- 文件操作：C 标准文件读写函数

\- 数据结构：结构体

\- 开发环境：Windows / MSYS2 UCRT64



\## 运行方法



\### 1. 获取项目代码



```bash

git clone https://github.com/geniusQ16/C-Library-Management.git

cd C-Library-Management

```



\### 2. 编译程序



确保已经安装 GCC 编译器，然后执行：



```bash

gcc main.c -o library.exe

```



\### 3. 运行程序



在 MSYS2 UCRT64 终端中执行：



```bash

./library.exe

```



\## 数据说明



程序使用本地文件保存图书记录。请在删除或修改数据前做好备份，避免误操作造成数据丢失。
